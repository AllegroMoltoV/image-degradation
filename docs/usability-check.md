# 使い心地の確認の手順

## 目的

シンプルJPEG劣化を OBS Studio で実際に使い、配信で使える見た目と負荷になっているかを確かめます。計算の正しさは統合テストで確かめ済みです。ここで見たいのは、JPEG を保存し直したような見た目の出来、既定値と最大の崩れ具合、動きのある映像でのちらつき、負荷の感じ方です。

## 準備

確認の前に、Claude Code がビルドした Windows 版を `%PROGRAMDATA%\obs-studio\plugins\simple-jpeg-crunch\` に導入し、OBS Studio で読み込まれ、フィルターの一覧に出ることを確かめます。導入の前に、ほかの Claude Code のセッションが OBS Studio を使っていないことを確かめてください。

## 手順

1. カメラの映像キャプチャデバイスか画像のソースを右クリックし、フィルターを開きます。映像フィルターの追加から「シンプルJPEG劣化」を選びます。付けた直後は、既定のガビガビ度 50 で崩れた映像になります。
2. 「ガビガビ度」のスライダーを 0 から 100 まで動かし、崩れ具合を見比べます。0 では元の映像のままです。
3. カメラの前で体を動かすなど、動きのある映像でガビガビ度を 50 と 100 にして、ブロックのちらつきを見ます。
4. ガビガビ度を 100 にしたまま、配信やプレビューの動作の重さを見ます。OBS Studio の「統計」の画面で、描画の遅延によるフレームの欠落の増え方も見てください。

## 伺いたいこと

次の 5 点について、感じたことを自由に書いてください。

- 保存し直しを重ねた JPEG らしさ
- 既定のガビガビ度 (50) の妥当性
- 最大 (100) の崩れ具合の過不足
- 動きのある映像でのちらつきの気になり具合
- そのほか気になったこと (負荷、項目名など)

## 終了後

OBS Studio を終了してから、Claude Code に知らせてください。受け取った感想は一覧にし、対応案を添えて確認をお願いします。
